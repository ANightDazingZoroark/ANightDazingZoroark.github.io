# Why I don't mod Bedrock anymore
<img src="/images/nomorebedrock.jpg" class="image-center"/>

In case that wasn't obvious... yeah, I don't do Bedrock anymore. This page wasn't even necessary to begin with, but I STILL get comments asking me about stuff that I made during my Bedrock days that I would have since forgotten. Especially with how my old YouTube videos about that have like, 10k+ views. I would have made a video about this to make it easier to explain for the fresh-from-the-womb single digit IQs that can't read, but as this website is the first place they end up in when trying to find those headcrab addons, I put this essay on the sidebar just for some visibility on this matter.

## Bedrock's API sucked
There used to be a point in time where I believed Bedrock could legitimately overtake Java. Like, no exaggeration. I used to believe that. With hindsight that was a really naive viewpoint, but a series of events involving my negative experiences with how modding worked was a major factor.

You see, during my last days on Bedrock, the API had the following problems:
* No custom biomes. They used to work, but the Caves and Cliffs update broke them
* Very limited UI options. To this day, the only UI possible was a form-type UI. Good luck making UIs similar to crafting tables or furnaces.
* Just Bedrock being a mess in general. We all know the "Bugrock" jokes, come on.
* The API changes every second. Yeah, no wonder I stayed on just 1 version after the move to Java.

Combined with how shitty the codebase for Prehistoric Rift was... yeah it was not fun. Looking back I could have made some kind of Python program that would automate everything easier, but this was just one factor.

This was just the worst. It's common knowledge that Bedrock's target audience is children, and unfortunately, children are completely retarded. And guess fucking what, THERE WERE STILL CHILDREN THAT COMPLAINED ON YOUTUBE AND EVEN GITHUB THAT THEY CAN'T FIND THE ITEMS NOR TAME THE DINOSAURUS. Same with how to tame the Tyrannosaurus. The MCPEDL page literally explained that in order to tame them, you had to kill them to get their eggs, AND THEY STILL KEPT ASKING ME HOW TO TAME TO THE POINT WHERE I HAD TO MAKE A FUCKING VIDEO EXPLAINING.
