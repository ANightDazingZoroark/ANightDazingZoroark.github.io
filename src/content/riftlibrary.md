# RiftLibrary
<img src="/images/riftlibrary.png" alt="RiftLibrary" class="image-left" width="128"/>

RiftLibrary is my personal library mod. It's a fork of GeckoLib with the following changes:
* Hitboxes using Blockbench's bounding boxes
* Ride positions using locators
* Animation blending
* Hold on last frame for animations
* Support for Bedrock's particle API (including attaching them to models!)
* Better Molang support (queries and variables)
* Messages from animations
* Server-based models
* Animation controllers as Finite State Machines

It's a hard fork, meaning that lots of classes and packages have been moved around and changed to the point where it's suffering from a Theseus's ship dilemma.

Despite being personal, it's open to use for any modder willing to ditch GeckoLib for something better (too bad current docs are insufficient). There's also a [Blockbench plugin](https://github.com/Rift-Modding-Group/RiftLibrary-Blockbench-Extension) for assisting in making hitboxes.
